# Civilian & Emotes

## Civilian radial & emotes — `configs/cfg-civilian-sh.lua`

Data-driven lists for the civilian layer (RP-only). LACORE does **not** play animations itself — it
bridges to DPEmotes or RPEmotes (auto-detected) and each radial button runs `/e <emote>` on the
detected resource.

```lua
CivConfig = CivConfig or {}

-- Key that opens the civilian radial (rebindable under Settings → Key Bindings).
CivConfig.radialKey = "B"

-- Emote catalogue. `emote` = the DPEmotes/RPEmotes name run via /e.
CivConfig.emotes = {
    { cat = "Gestures", id = "wave",     label = "Wave",      emote = "wave" },
    { cat = "Poses",    id = "handsup",  label = "Hands Up",  emote = "handsup" },
    { cat = "Idle",     id = "smoke",    label = "Smoke",     emote = "smoke" },
    { cat = "Idle",     id = "leancar",  label = "Lean",      emote = "lean" },
    -- …
}
```

| Field | Meaning |
| --- | --- |
| `cat` | Groups buttons into radial pages. |
| `id` | Unique internal key. |
| `label` | Text shown on the button. |
| `emote` | **Must** match an emote name in your installed DPEmotes/RPEmotes catalogue. |

<Callout type="info">
  Run `/emotemenu` in-game to see the exact emote names your emote pack provides, then use those in
  `emote`. The defaults are common DP/RP names — adjust to your pack. See
  [Civilian Layer](/features/civilian).
</Callout>

## Turf / gang war — `configs/cfg-turf-sh.lua`

Kill-based territory capture for civilian orgs. **Off by default.**

```lua
Turf.enabled     = false   -- master switch (false = nothing runs)
Turf.drawMarkers = false   -- in-world zone cylinder (off — heavy; blips show ownership)

-- Capture tuning
Turf.killsToCapture     = 5    -- qualifying kills in a zone to flip it
Turf.decaySeconds       = 90   -- no kills for this long → capture progress drops by 1
Turf.cooldownMin        = 15   -- minutes a zone is locked after being captured
Turf.influenceOnCapture = 100  -- org influence awarded for taking a zone
Turf.influencePerKill   = 5    -- org influence per qualifying kill

Turf.zones = {
    { id = "grove", label = "Grove Street",
      center = vector3(-100.0, -1620.0, 30.0), radius = 90.0, color = "#2ecc71" },
    -- add your own zones
}
```

| Field | Meaning |
| --- | --- |
| `id` | Unique zone key. |
| `label` | Display name. |
| `center` | World centre `vector3`. |
| `radius` | Zone radius (metres). |
| `color` | Hex colour for the map blip/HUD. |

<Callout type="warning">
  Enable with `Turf.enabled = true` and set your own zone coordinates — the samples are placeholders.
  Anti-farm protection requires the killer to be inside the zone and applies a per-victim cooldown.
</Callout>

## Radial props — `CivConfig.props`

The props on the civilian radial (and `/prop <id>`). Server-synced, so everyone sees them, and only
models from this list can be placed.

```lua
CivConfig.propLimit = 10
CivConfig.props = {
    { id = "cone",    label = "Traffic Cone", model = "prop_roadcone02a" },
    { id = "barrier", label = "Barrier",      model = "prop_barrier_work05" },
    -- …
}
```

Each player may place up to **`CivConfig.propLimit`** props at once (default `10`). At the limit a
further prop is refused with a notification — pick one up first.

## Scenery prop spawner — `configs/cfg-props-cl.lua`

A separate tool (`/propspawner`), with its own catalogue grouped into categories:

```lua
PropConfig = {
    {
        categoryName = "Roadworks",
        description  = "Road signs used for public works related roleplay",
        components = {
            { name = "Large Striped Cone", spawn = "prop_roadcone01a" },
            { name = "Flagger Paddle",     spawn = "prop_flagger_sign_01" },
            -- …
        },
    },
    -- more categories
}
```

Add a category with a `categoryName`, `description`, and a `components` list of `{ name, spawn }`
(the `spawn` is the GTA prop model name).

## Fines & notifications — `CivConfig.fines`, `CivConfig.notify`

```lua
-- What a civilian is told about. false = they only find it in /citizen → Legal.
CivConfig.notify = {
    warrant = true,   -- a warrant was issued / lifted on your character
    license = true,   -- an officer suspended / revoked / reinstated a licence
}

CivConfig.fines = {
    enabled = true,     -- false = fines are a number on the record again, nothing is owed
    payment = "auto",   -- "auto" | "rp" | "external"
    dueDays = 7,        -- unpaid fines past this show as OVERDUE
}
```

| `payment` | Meaning |
| --- | --- |
| `"auto"` | Framework running → bank (then cash) is charged. Standalone → RP confirmation. |
| `"rp"` | Always the RP confirmation. |
| `"external"` | LACORE fires `lacore:api:finePayRequested`; your script charges the player and calls `exports.lacore:MarkFinePaid(license, recordId)`. |

See [Civilian Layer → Fines](/features/civilian#fines).

## Civilian jobs — `CivConfig.jobs`

![A civilian job shift and the three shipped jobs](/img/features/civ-jobs.svg)

```lua
CivConfig.jobs = {
    enabled       = true,
    payment       = "auto",   -- "auto" = pay through the framework when one runs · "off" = never pay
    setOccupation = true,     -- clocking in writes the job onto the character
    list = {
        {
            id = "courier", label = "Courier",
            depot   = { x = 215.8, y = -810.1, z = 30.7, r = 3.5 },
            blip    = { sprite = 478, color = 46, scale = 0.8 },
            vehicle = { model = "boxville2" },          -- optional: spawn = { x, y, z, h }
            mode = "random", pick = 5,                  -- or mode = "route" (every stop, in order)
            action = { seconds = 5, label = "Handing over the parcel", onFoot = true },
            pay = { perStop = 80, bonus = 200 },
            stops = {
                { x = 25.7, y = -1347.3, z = 29.5, r = 22.0, label = "24/7 Strawberry" },
                -- …
            },
        },
    },
}
```

| Field | Meaning |
| --- | --- |
| `id` / `label` | Unique key / name shown in the hub, on the blip and as the occupation. |
| `depot` | `{ x, y, z, r }` — where you clock in and out. |
| `vehicle` | `{ model, spawn }`. Without `spawn` the vehicle appears on the road nearest to the depot. Leave `vehicle` out for a job on foot. |
| `mode` | `"route"` = every stop in the listed order · `"random"` = `pick` stops drawn from the list, new each shift. |
| `stops` | `{ x, y, z, r, label }` — `r` is how close counts as "there". Distances are measured flat, so a `z` that is a little off does not break a stop. |
| `action` | `seconds`, `label`, and one of `onFoot = true` (get out first) or `inVehicle = true` (stay seated, full stop). `scenario` optionally plays a GTA scenario on foot. |
| `pay` | `{ perStop, bonus }` in USD. Only paid on a framework server with `payment = "auto"`. |
| `achievement` | Optional achievement id unlocked by a finished shift. |

<Callout type="warning">
  The **depots** are a starting point — check them once on your map. The stops of the shipped bus
  and sanitation jobs are the bus stops from `cfg-busroutes-cl.lua`; the courier stops are the
  standard store locations.
</Callout>

### Legacy activities — `CivConfig.activities`

The pre-4.2.0 waypoint chains (no vehicle, no pay, no server-side stop check) still work, so an
existing config keeps running. The shipped list is empty now; new work belongs in `CivConfig.jobs`.

```lua
CivConfig.activities = {
    { id = "tour", label = "City Tour", blip = { sprite = 318, color = 2, scale = 0.8 },
      steps = {
          { x = -322.6, y = -1545.4, z = 27.5, r = 3.5, label = "Start" },
          { x = -245.0, y = -1469.0, z = 30.5, r = 3.5, label = "Last step completes the run" },
      } },
}
```
