# Configuration

LACORE is configured in three layers:

1. **Convars** in `server.cfg` — secrets (Discord token, webhooks) and a few runtime toggles. Secrets
   live here so they never end up in the code or in client downloads. See [Server Convars](/configuration/convars).
2. **`config.lua`** — the main gameplay/world config (agencies, call center, time (`SyncGameTime`), transit, AOPs, …).
3. **`configs/*-sh.lua` / `*-cl.lua` / `*-sv.lua`** — one file per feature. The suffix is the realm:
   `-sh` shared (client **and** server), `-cl` client-only, `-sv` server-only.

<Callout type="info">
  Every file in `configs/` and `config.lua` is **escrow-open** — you can open and edit them freely, and
  most carry a comment header explaining each option. After editing, **restart the resource** for the
  change to apply. Convars keep secrets out of the code and out of client downloads.
</Callout>

## Config file map

Every config file, what it controls, and where it's documented. Files marked *(in-file)* are
self-documented by the comment header at the top of the file. The same map also ships with the
resource as **`configs/CONFIG-INDEX.md`** (since 3.4.2).

### Core & world

| File | Scope | Controls |
| --- | --- | --- |
| `config.lua` | shared | [Main config](/configuration/main) — general settings, call center, time (`SyncGameTime`), vehicles (since 3.4.4 the big data tables live in their own files below) |
| `configs/cfg-agencies-sh.lua` | shared | *(in-file)* — every department the duty window and CAD/MDT know: tag, name, loadout, wallpaper |
| `configs/cfg-regions-sh.lua` | shared | [World, blips & props](/configuration/world) — dispatch districts: regions, map colours, GTA-zone mapping |
| `configs/cfg-gametext-cl.lua` | client | *(in-file)* — GTA text overrides: key hints, session/AOP notices, member-restriction messages |
| `configs/cfg-busroutes-cl.lua` | client | *(in-file)* — public-transport bus stops + the routes chaining them |
| `configs/cfg-features-sh.lua` | shared | [Feature Toggles](/configuration/features) — enable/disable any component (e.g. run only the MDT/CAD) |
| `configs/cfg-server-sv.lua` | server | [Discord & Duty](/configuration/discord) — devmode, Discord auth, duty roles, agency whitelist, vehicle-spawner permission, webhooks |
| `configs/cfg-branding-sh.lua` | shared | [Branding & Backup](/configuration/branding) — your community/server name everywhere |
| `configs/cfg-notify-sh.lua` | shared | [Notifications](/configuration/notifications) — LACORE / native GTA / custom notify resource |
| `configs/cfg-hud-sh.lua` | shared | [HUD & player list](/configuration/hud) — HUD master switch, per-element toggles, `playerlistStyle` (`"duty"` / `"minimal"` / `"bar"`), `settingsCommand` |
| `configs/cfg-blips-cl.lua` | client | [World, blips & props](/configuration/world) — map blips |
| `configs/cfg-areas-cl.lua` | client | [World, blips & props](/configuration/world) — area labels / zones |
| `configs/cfg-spawns-sh.lua` | shared | [World, blips & props](/configuration/world) — map-based spawn picker (capture points with `/spawnpoint`) |
| `json/emojis.json` | server | [Gameplay modules](/configuration/gameplay-modules) — emoji shortcodes used in chat (moved out of `configs/` in 3.4.3) |
| `configs/locale-sh.lua` | shared | [Gameplay modules](/configuration/gameplay-modules) — registered languages for the `T()` system |
| `configs/cfg-report-sh.lua` | shared | [Bug Reports](/user-guide/bug-reports) — `/lacorereport`: command name, cooldown, max length, categories |

## Localisation

All user-facing strings are localised (`en` / `de` / `ru`). The active language is `Language` in
`config.lua`; the MDT/NUI can use a separate one via `MdtLanguage`. Editing strings, adding a
language and the whitelabel system are covered on the
[Localisation page](/configuration/localisation).
