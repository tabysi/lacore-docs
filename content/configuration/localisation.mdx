# Localisation & Translations

LACORE ships fully localised in **English, German and Russian**. Two separate string systems cover
the resource:

| System | Covers | Files | Lookup |
| --- | --- | --- | --- |
| **Lua** (`T("key")`) | Chat messages, notifications, HUD text — everything drawn by Lua | `lang/en.lua`, `de.lua`, `ru.lua` | Falls back to English per key; a missing key renders `[key]`. |
| **NUI** (`t("key")`) | The MDT/CAD terminals, dispatch console, phone, profile — everything in the web UI | `lang/en.json`, `de.json`, `ru.json` | Falls back to English per key. |

## Picking the language

```lua
-- configs/config.lua
Language    = "en"   -- core language: en / de / ru
MdtLanguage = ""     -- separate language for the NUI (MDT/dispatch/profile); "" = follow Language
```

`MdtLanguage` exists so the game can run in one language while the terminals run in another — e.g.
German server, English CAD (like a real US terminal).

## Editing translations

**Lua strings** (`lang/*.lua`) are plain text and escrow-open — edit any string, restart the
resource, done. The same applies to adding a whole new Lua-side language: create
`lang/<code>.lua` defining `_PVP_LANG.<code> = { … }` (copy `en.lua` as the template — every
`lang/*.lua` is loaded automatically) and set `Language = "<code>"`.

<Callout type="warning">
  **NUI strings are baked into the UI build.** The `lang/*.json` files document every key, but the
  shipped `nui/dist` bundle has en/de/ru compiled in — editing the `.json` files on a customer
  install has **no effect** on the terminals. If you need another NUI language or a changed NUI
  string, ask in the [Discord](https://discord.gg/b6YbvVEvYp) — adding a language to a build is a
  quick job on our side.
</Callout>

## Renaming CAD labels without translating (whitelabel)

Most "I want this to say something else" cases aren't translation at all — they're branding. The
**whitelabel** config renames any MDT/CAD label at runtime, no rebuild needed, and wins over every
locale:

```lua
-- configs/cfg-mdt-labels-sh.lua
MdtLabels = {
    -- ["mdt_title"] = "MY COUNTY CAD",
}
```

See [MDT & Dispatch — whitelabel](/features/mdt-and-dispatch) and
[Branding](/configuration/branding) for the community-name side.

## Rules the docs follow

- Every user-facing string in LACORE goes through `T()` / `t()` — nothing visible is hardcoded, so
  a translation is never chasing loose strings.
- `T(key, ...)` supports `string.format` arguments; NUI keys use `{var}` placeholders.
- A key missing from the active language falls back to English; a key missing everywhere renders
  as `[key]` — if you see one in-game, report it with [`/lacorereport`](/user-guide/bug-reports)
  (category *Translation*).
