# Downloads & versions

**Dashboard → Downloads** shows the **current LACORE version** and the full version history, each
release with its notes and a link into these docs.

## Where the files actually come from

LACORE is escrow-protected, so the resource itself is **not** a file on this page. Downloads and
updates come through **FiveM Keymaster**, tied to the Cfx account you used at purchase — the
dashboard tells you *which* version is current, Keymaster hands you the files.

<Callout type="info">
  Updates are included for the lifetime of your license. If a new version is out, grab it from
  Keymaster and follow the [update guide](/getting-started/updating) — replace the folder, restart,
  and your config and license key stay untouched.
</Callout>

## Checking what your servers run

The [Servers](/customer-portal/servers) page shows the version each of your servers reports, so you
can see at a glance which ones are behind. In-game, `/lacore version` answers the same question.
