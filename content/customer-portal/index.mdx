# Customer Portal (shut down)

The customer portal and online dashboard at **lacore.netica.dev** have been shut down with
**4.2.0**. LACORE now runs **fully offline**: the resource makes no calls to the LACORE home
service, and nothing needs to be linked, activated or signed in to.

Everything in-game keeps working — MDTs/CADs, dispatch, BOLOs, records, civilians, local bans and
warns, Big Brother, the anticheat and the in-game [admin panel](/user-guide/admin-panel).

![What keeps working and what is gone](/img/features/offline-build.svg)

## What the portal did — and where that is now

| Portal page | Now |
|---|---|
| **License keys** | Not needed. `set lacore_license_key` is no longer read; `/lacore doctor` reports it as *not needed*. You can remove the line from `server.cfg`. |
| **Servers** | Gone. There is no online server list any more. `/lacore version` shows what a server runs. |
| **Community page** | Gone. The public roster page and its applications are no longer available. |
| **Server config** | Edit the files in `configs/` and restart. See [Configuration](/configuration). |
| **Dispatch (live ops)** | The hosted dispatcher is gone. The self-hosted bridge still works — see [Web dispatcher](/features/webdispatch). |
| **Downloads & versions** | Downloads and updates come through **FiveM Keymaster**, tied to the Cfx account you used at purchase. Then follow the [update guide](/getting-started/updating). |
| **Players & sharing** | Local bans and warns only (`data/banlist.json`, `/lacore bans list` / `import`). The shared playerbase and cross-community sharing are shut down. |
| **Anticheat flags** | Use the in-game [admin panel](/user-guide/admin-panel) (`/admin`), `/bblog` and your own Discord webhooks. |
| **Activity log** | Use the in-game admin panel and Big Brother (`/bblog`). |
| **Bug reports** | `/lacorereport` still works and goes to your own Discord when `Webhooks.BugReport` is set in `configs/cfg-server-sv.lua`. See [Bug reports](/user-guide/bug-reports). |
| **Support tickets** | Ask on the [Discord](https://discord.gg/b6YbvVEvYp) or in [GitHub Discussions](https://github.com/tabysi/pvp-corev3-community/discussions) — see [Support & FAQ](/support). |
| **Payments** | Discontinued. Use the confirmation Tebex emailed you at checkout. |
| **Surveys & rebate** | Discontinued. |
| **Team** | Discontinued. |
| **Partner program** | Discontinued. |

<Callout type="warning">
  **If you changed settings on the old dashboard:** they are cached in `data/remote-config.json` and
  still override your `configs/` files at start — the server console says so. Delete that file to
  go back to your local configs only.
</Callout>
