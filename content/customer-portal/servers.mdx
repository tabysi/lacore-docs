# Servers

Every server linked to your account (via a [license key](/customer-portal/license-keys)) appears on
**Dashboard → Servers** as a card. The list refreshes itself every 30 seconds while the page is
open, and the header shows how many of your servers are online.

## What a server card shows

| Field | Meaning |
|-------|---------|
| **Status** | Online / Offline. A server counts as offline once its last heartbeat is more than **3 hours** old. |
| **Players** | Current players / slots. |
| **Version** | The LACORE version that server is running. |
| **Last seen** | When it last checked in. |
| **LICENSED / UNVERIFIED** pill | `LICENSED` means an active key of yours matched at the last heartbeat. `UNVERIFIED` means it reported in but no active key matched. |

If you gave the server a custom name, its raw `sv_hostname` is shown underneath.

### Key and URLs

Each card names the **key** the server last reported with (a link to License keys) — or says
*none — unlicensed*. The footer buttons open the server's **web dispatcher** and, when the key is
known, its public **community page**.

## What you can do

- **Rename** — a friendly name (up to 80 characters) that replaces the hostname in your dashboard.
  It changes nothing in-game.
- **Remove** — takes the server off your list. If it is still running with a valid key it
  **re-appears on its next heartbeat**, so this is mainly for clearing out old entries.
- **Dispatch** — opens the [web dispatcher](/features/webdispatch) for that server.

<Callout type="info">
  Server missing? Check that `setr lacore_license_key "…"` is in its `server.cfg`, that the key is
  still active, and that the server has actually started — registration happens on its first
  heartbeat, not at purchase.
</Callout>
