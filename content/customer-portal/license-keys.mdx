# License keys

A **license key** links a running server to your dashboard account. Once linked, the server shows up
under [Servers](/customer-portal/servers), can pull its [config](/customer-portal/server-config)
online, and unlocks any paid add-ons your account owns.

<Steps>

### Create a key

On **Dashboard → License keys**, optionally type a label (e.g. "Main RP server") and hit
**+ CREATE KEY**. Keys look like this:

```
LACORE-XXXXX-XXXXX-XXXXX
```

### Paste it into server.cfg

The dashboard shows the ready-made line with a **COPY** button — drop it into your `server.cfg`:

```cfg
setr lacore_license_key "LACORE-XXXXX-XXXXX-XXXXX"
```

### Start the server

The server reports in on startup and appears under **Servers**, verified as yours. Its config pull
starts about 20 seconds after boot.

</Steps>

## Managing keys

Each key card shows its label, when it was created and when it was **last seen** (or "never used"),
plus a **COPY CFG** button for the `server.cfg` line.

- **You can hold up to 10 active keys.** Revoke one before creating another if you hit the cap.
- **Revoke** turns a key off without deleting it — any server still using it goes *unlicensed* on
  its next heartbeat and keeps running on its local config. Revoked keys stay in the list, greyed
  out, as a record.

<Callout type="warning">
  A key proves a server is **yours** and stays fully visible in your dashboard so you can copy it
  again later. Treat it like a password — don't paste it in screenshots or public channels. If it
  leaks, revoke it and create a fresh one.
</Callout>
