# MDT Desktop

`/mdt` does not throw a CAD window at you any more — it **boots the computer the CAD runs on**:
a POST screen, a sign-in screen, then a desktop with your department's CAD as an app on it.

![What /mdt does: boot, sign in, desktop, CAD](/img/mdt/mdt-desktop-flow.svg)

Boot and sign-in run **once per shift**. Every `/mdt` after that resumes from standby straight to
the desktop; going off duty puts the computer back to a cold boot.

> 📑 **Related:** [Using the MDT](/user-guide/mdt) · [CAD Terminals & Routing](/configuration/cad-terminals) · [Dispatch Console](/user-guide/dispatch-console) · [Command Reference](/commands)

---

## 🖥 The three screens

1. **Boot** — four stages, like a machine that actually starts:
   the **firmware screen** (brand, firmware version, processor, a memory test counting up to
   8192 MB), the **POST** table detecting storage, radio, GPS, plate camera, printer and the
   dispatch link, the **boot loader** (`Booting from MDT-DISK0`), and the **system splash** — logo,
   dots, a progress bar and the service it is waiting for. The whole sequence is scaled to
   `bootSeconds` in `configs/cfg-mdtos-sh.lua` (default 7 s, `0` skips it).
2. **Sign in** — clock, date, your character with the callsign and department under it, the
   password already filled in. **Sign in** (or Enter) plays the welcome animation and drops you on
   the desktop.
3. **Desktop** — icons on the left, a taskbar at the bottom with the Start menu, the machine name,
   your callsign and the clock.

<Callout type="info">
The sign-in is deliberately an **animation**, not a password check: LACORE has no per-player
computer password on the server, so a real prompt would let every password through and only look
like security.
</Callout>

## 📐 The screen is your CAD's screen

The computer is **exactly as big as the terminal that runs on it**. The LAPD Mobile Client is a
tall narrow strip in the corner, the EMS CAD a wide box, the 9100-T a 3:2 CRT — the machine takes
that shape, and the CAD then fills its screen edge to edge instead of floating on a desk that is
the wrong size.

The size **and the position** are measured from the terminal itself the first time you open it and
remembered on that computer, so a re-skinned, resized or moved terminal keeps matching. That matters
for the EMS / Fire CAD in particular: it keeps its own window settings and centres itself, so
nothing else could have known where it was going to appear.

Each app opens at the size it needs — the map and the call list wide, the calculator narrow, the
query tall enough for a record card — clamped so nothing starts outside the screen. On the Sheriff
CAD's 920 × 640 and Spillman's 1220 × 790 that means several windows side by side; drag them where
you like.

**On a narrow machine — the LAPD client's ≈380 px strip — the desktop works like a small screen:**
every app opens full-screen and the taskbar switches between them, the taskbar drops its labels and
scrolls, the Start menu fills the width, and the desk icons flow into two columns. Nothing opens
half off the edge where you cannot reach it. The maximise button still shrinks a window down if you
want to see two at once.

## 🧩 What is on the desktop

| App | What it does |
| --- | --- |
| **Your department's CAD** | Exactly the terminal `/mdt` would have opened — LAPD, Sheriff, Agency, EMS, 9100-T, Pennsylvania or Spillman Flex |
| **Dispatch** | The dispatch console — only for a unit that is actually a dispatcher |
| **Supervisor** | The oversight terminal — only when the server knows you as a supervisor |
| **Calls** | Every open call. Click one and the CAD opens with that call selected |
| **Units** | Everyone on duty with their status, crew and department |
| **BOLOs** | The active BOLOs, dangerous ones marked |
| **Radio** | The dispatch channel: read it and talk on it |
| **Query** | Run a person or a plate, exactly like the CAD does — the result is the full record card |
| **Map** | The live map with every call, the same tiles the terminals use |
| **History** | Closed incidents; click one to look at it |
| **Citations** | The charge picker: who, citation or arrest, tick the charges, issue |
| **My Activity** | Your own numbers — arrests, citations, warnings, calls closed, reports, evidence and duty time |
| **Penal Code** | The charge list, searchable by code or title — fines and jail time included |
| **Notes** | The bulletin board: read it and pin a note, same board every terminal shows |
| **Notepad** | Your own scratchpad. Stays on this computer, one per callsign |
| **Calculator** | A calculator that calculates |
| **Clock** | Time, date and how long the computer has been running this shift |
| **Task Manager** | What is open, including the CAD, with **End task** |
| **Minesweeper** | For the quiet shift. Left click opens, right click flags |
| **Help** | What the keys do and what this machine is |
| **Settings** | Wallpaper, accent colour, window opacity and size, and *About this PC* |
| **Intranet** | The department page: active BOLOs, open calls, units on duty and the latest board notes |
| **Recycle Bin** | Empty. It is there for the look |

One click opens an icon — no double-click, you are in a moving car. Windows have the usual
minimise, maximise and close buttons and can be dragged around the screen. **Right-click the
desktop** for Refresh, a new board note and Personalise.

The Start menu has a search box, every app in alphabetical order, tiles for the ones you use most,
and **Sign out** / **Shut down** at the bottom. The taskbar pins the terminals and shows every open
window, with the tray and clock on the right.

## ⌨ Getting around

| Key / click | What happens |
| --- | --- |
| Click an icon | Opens that app |
| `Esc` in the CAD | Closes the CAD and lands back on the desktop — the computer stays on |
| `Esc` on the desktop | Closes the open window, then the Start menu, then shuts the computer down |
| `/mdt` again | Shuts everything down (the same toggle it always was) |
| Start → **Sign out** | Closes it and asks for the sign-in again on the next `/mdt` |
| Start → **Shut down** | Closes it; the next `/mdt` resumes from standby |

---

## 🔧 Turning it off

The desktop is one switch: `cad.os = false` in
[`cfg-features-sh.lua`](/configuration/features), and every terminal opens directly again, exactly
like before. Everything else — timings, wallpaper, the machine name and whether the small apps and
the decorative icons are there at all — lives in
[`configs/cfg-mdtos-sh.lua`](/configuration/cad-terminals#mdt-desktop--configscfg-mdtos-shlua).

<Callout type="warning">
The in-car dashboard screen never shows the desktop — a dashboard has no cursor to click an icon
with, so it keeps mirroring the CAD itself.
</Callout>
