# Bug Reports

**`/lacorereport`** opens a small form for reporting a bug in LACORE itself — not a player, not an in-character incident. What you write goes to **your server's own Discord**, through the `lacore_webhook_bugreport` webhook your server owner sets. It does **not** go into your server's own database, and it is not a replacement for `/report` (reporting a *player*) or a support ticket.

> ⚠️ **Changed in 4.2.0:** reports no longer reach the LACORE dashboard — the dashboard has been shut down and LACORE runs fully offline. The Discord webhook is now the only place a report goes. If your server has none set, the form still accepts the report, but it is not delivered anywhere.

![What keeps working and what is gone](/img/features/offline-build.svg)

> 📑 **Related:** [Commands & Keybinds](/commands) · [In-Car Screen](/user-guide/in-car-screen)

**Which channel for what?** `/lacorereport` is the quickest path **in-game** and reaches your
server team. To reach the LACORE team — bugs in the product, feature requests, discussion — use the
[Discord & GitHub Discussions](/support).

## ✍️ Using it

```bash
/lacorereport
```

A form opens: pick a **category** (Bug, Exploit, Translation, Suggestion, Other by default), write what happened, and send it. There is a short cooldown between reports — the form shows a countdown if you try again too soon — so it stays a report tool, not a chat channel.

> ℹ️ **No typing shortcuts here either way** — this is the real game UI, not a dashboard screen rendered onto a texture, so there is nothing unusual about the keyboard. If you have trouble typing, check that nothing else is holding NUI focus.

What the Discord message contains:

- The category and what you wrote.
- Your account name and, if you have one, your **character name** — so a report can be traced back to you.

Nothing you type is sent anywhere else.

## 🛠 For server owners

### Where reports go: your Discord

```lua
-- configs/cfg-server-sv.lua
Webhooks.BugReport = GetConvar("lacore_webhook_bugreport", "")
```

Set the `lacore_webhook_bugreport` convar in `server.cfg` to receive every report in your own Discord. Without it, reports have nowhere to go. `@everyone` / `@here` in a report are stripped, so the form cannot be used to ping a role.

### Turning it off, renaming it, tuning it

```lua
-- configs/cfg-report-sh.lua
Report.enabled     = true                -- master switch
Report.command     = "lacorereport"      -- rename if something else owns this name
Report.cooldownSec = 120                 -- seconds between two reports, per player
Report.maxLength   = 800                 -- longest report a player can type
Report.categories  = { "Bug", "Exploit", "Translation", "Suggestion", "Other" }
```

`Features.bugreport` (`configs/cfg-features-sh.lua`) is the same switch from the shared feature-toggle file, for owners who prefer to turn features off from one place — either setting disables the command entirely, with no trace left in `/help`.

The cooldown is enforced **on the server**, not just shown by the form: a modified client cannot skip the wait, because the server keeps its own timer per player and rejects an early submit regardless of what the form displays.
