# Troubleshooting

The common problems from every corner of LACORE on one page, grouped by symptom. Each entry links
to the page with the full context.

<Callout type="info">
  **Start with the built-in diagnostics.** `/lacore doctor` (console or staff) runs the full health
  check; `/lacore status`, `/lacore db` and `/lacore modules` narrow it down. See
  [Server Installation](/getting-started/installation#first-boot-diagnostics--owner-commands).
</Callout>

## Connecting & first start

| Symptom | Cause / fix |
| --- | --- |
| Stuck at **"Checking bans..."** | oxmysql isn't reachable or the connection string is wrong — check the console for oxmysql errors. |
| Script errors on every spawn | An optional resource is half-installed. Since 3.4.5, `blip_info` and `bob74_ipl` are auto-detected and optional — make sure you run the current build. |
| Player is **"out of the session"** | No RP name set yet — `/char`, fill it in, save. See [Civilian & Vehicles](/user-guide/civilian-vehicles). |
| "Members only" rejection | The join whitelist is on and the player lacks the Discord **Member** role — see [Access control](/configuration/discord#access-control-whitelist--discord-onoff). |

## MDT / CAD

| Symptom | Cause / fix |
| --- | --- |
| MDT won't open | Not on duty — `/onduty <agency> <callsign>`. LEO tools are gated server-side. |
| `/onduty` refused | The agency is gated by role/ACE — check with [`/dutyaccess`](/configuration/discord#checking-it-works). |
| Mouse turns the camera / clicking fires the weapon | Camera-look and attack controls are blocked while the MDT is open — if not, the build is outdated. |
| MDT covers the view | Drop opacity in Settings or drag it to a corner; Settings → Position has presets. |

More: [Using the MDT — Troubleshooting](/user-guide/mdt#troubleshooting).

## Dispatch map

| Symptom | Cause / fix |
| --- | --- |
| Blank map tiles | `lacore-maps` isn't started, or `DispatchTileBase` points at an unreachable URL — `ensure lacore-maps`. |
| Map markers offset | Tile calibration; needs an in-game reference point to tune. |

## Voice, phone & 911

| Symptom | Cause / fix |
| --- | --- |
| 911/311 caller can't hear dispatch | `pma-voice` isn't running — it's a **hard dependency** ([Installation](/getting-started/installation#prerequisites)). |
| Phone won't open | `Features.phone` is off, or another resource owns the **F1** bind — rebind in FiveM key settings. |
| Camera app can't upload | `screenshot-basic` isn't installed (optional dependency of the camera app). |

## Emotes & civilian

| Symptom | Cause / fix |
| --- | --- |
| Emotes don't play | Install DPEmotes or RPEmotes-Reborn — the radial bridges to whichever is present. See [Civilian Layer](/features/civilian). |
| `/hu` / `/hh` keys clash with another script | Turn `Features.rpemotes` off — U/X are then left free. See [Keybinds](/getting-started/keybinds). |
| Two chat lines per message | You run an external chat resource — set `ExternalChat = true` ([Discord & Duty](/configuration/discord#external-chat)). |
| No NPC traffic on the streets | `EntityLockdown = "strict"` (the anti-cheat default) — set `"inactive"` to get ambient traffic back ([details](/configuration/discord#entity-lockdown-anti-cheat-vs-npc-traffic)). |

## Permissions & supervisor

| Symptom | Cause / fix |
| --- | --- |
| "Did my ACE land?" | `/myperms` prints the caller's resolved permissions (ends with `supervisor=true|false`). |
| Supervisor panel refused | Needs the ACE object, a listed Discord role, grade or allowlist — see [Supervisor Panel](/configuration/supervisor). |
| Discord roles not read | Bot token + guild id convars missing, bot not in the guild, or **Server Members Intent** off — see [Discord role authentication](/configuration/discord#discord-role-authentication-built-in). |

## Anticheat

| Symptom | Cause / fix |
| --- | --- |
| "Is the anticheat even on?" | Yes — it ships **enabled in observe mode** (logs, never punishes). Switch `Mode = "enforce"` when the log looks right. See [Anti-Cheat & Security](/anticheat). |
| A trusted script's vehicles get deleted | Framework garages spawn server-side and can false-positive the entity sweep — `EntitySpam.skipOnFramework = true` (the default) handles it. |

<Callout type="warning">
  Still stuck? The fastest paths are **[`/lacorereport` in-game](/user-guide/bug-reports)** or the
  [community repo & Discord](/support). Include your version (`/lacore version`) and any console
  errors as text.
</Callout>
