# MDT & Dispatch

LACORE ships a shared law-enforcement backend that powers several **Mobile Data Terminals** and a
live **Dispatch console**. All terminals read and write the same incident/unit data, so a re-skin
never means duplicated work — a BOLO created in the LAPD MDT shows in the LASD CAD and the Agency
terminal alike.

![One shared CAD backend powering every LACORE terminal](/img/mdt/terminal-family.svg)

## The terminals

Open with `/mdt`. Which terminal you get is routed automatically by your department:

| Terminal | Look | Department trigger |
| --- | --- | --- |
| **LAPD** LACORE Mobile Client | white / grey | department contains `lapd` |
| **LASD** CAD / PCMS | amber / teal (own incident backend) | `lasd` / `sheriff` / `bcso` |
| **Agency** MDT | CHP dark-blue (re-skin of LAPD data) | any other LEO department |
| **EMS / Fire** | dark CAD | `AMR` / `fire` / `ems` / `medic` / `fd` |

Each terminal is draggable, opacity/scale adjustable, and theme-able. Settings persist per player.

### Agency MDT skins

The Agency MDT ships **thirteen** colour skins, picked from its own settings panel (the gear in the
title bar) and remembered per player.

![Agency MDT — thirteen skins, one terminal](/img/mdt/agency-skins.svg)

| Skin | For |
| --- | --- |
| CHP Blue | Highway Patrol — the default |
| SAHP Gold | State Highway Patrol |
| Ranger Green | Park Ranger / Game Warden |
| DOJ / BOI | Department of Justice, Bureau of Investigation |
| State Parks | State Parks department |
| Fish & Wildlife | Fish & Wildlife / conservation |
| Marshals | Marshals service |
| Cal Fire | Wildland fire agency |
| Fire / EMS | Fire & EMS command |
| Coroner | County Coroner |
| Slate · White · Black | Neutral, light and high-contrast |

A skin is a **palette and nothing else** — same markup, same data, same server rules; ten CSS
variables change. Two departments can run different skins of the same terminal side by side.

No two skins share an accent colour, because the accent is what fills the active function key and
is therefore what the eye lands on. Every skin's text on a filled accent key clears a 4.5:1 contrast
ratio — measured, not assumed.

## What the MDT does

- **Person & vehicle queries** — run a name, plate, or online player ID. Results show identity,
  licences, warrants, records, and **BOLO / charge hits**.
- **Incidents** — view outstanding calls, self-assign, add comments, set your status, resolve.
- **BOLOs** — create/cancel BOLOs against a name or plate; they broadcast to units and hit on query.
- **Charges & citations** — apply penal-code charges or issue citations to a person's record.
- **Evidence & reports** — file structured reports and log tagged evidence. See
  [Evidence & Reports](/features/evidence-reports).
- **Map** (LAPD MDT, rail section) — a live map of active incidents and units, with the server's
  own map images and named locations (see [Your own map](#your-own-map-overlays--named-locations)).
  Your own unit is outlined; clicking an incident loads it into the Active Incident panel. The
  ribbon keeps its nine tools. The **Agency MDT** has the same map behind the **MAP** key on its
  function bar, drawn in the colours of its skin; clicking an incident there opens the incident
  view. The **LASD** terminal opens it with the **MAP** command (MDC) or the **MAP** key (classic
  PCMS) — [details](/user-guide/lasd-cad#map).

## Dispatch console

Go on duty and open the console:

<Steps>

### Go on duty

```
/dispatch on
```

### Open the console

```
/dispatch open
```

</Steps>

The console shows a **live tile map** of incidents, units and callers, plus:

- **Zones & districts** — editable polygon boundaries with district colouring (admin-editable).
- **Unit management** — right-click a unit (list or map marker) for a context menu: assign, message
  (`@callsign`), voice-call, create an incident for them.
- **BOLOs & charges** — the same shared data as the MDT.
- **CCTV cameras on the map** — 📹 markers; click one to jump into the live camera. See
  [CCTV Surveillance](/features/cctv).
- **Attention tone** — play an alert tone to all on-duty units.

<Callout type="info">
  The console keeps game input alive (`SetNuiFocusKeepInput`) so you can still use voice (e.g.
  pma-voice) while dispatching. Escape closes the console without opening the GTA pause map.
</Callout>

### Caller trace (911 / 311)

![A 911 caller's location is found after 20–35 seconds on the line](/img/dispatch/caller-trace.svg)

By default a caller's postal, street and map blip show as soon as the call comes in. Turn on the
**trace** to make dispatchers work for it:

```lua
-- configs/config.lua
CallCenter = {
    Trace           = true,
    TraceMinSeconds = 20,
    TraceMaxSeconds = 35,
}
```

- Every answered call rolls a random trace time between `TraceMinSeconds` and `TraceMaxSeconds`.
- The call panel shows a **TRACE** countdown. Only connected time counts: putting the caller on
  hold pauses the trace.
- When it completes, postal and street appear and the caller's blip is placed on the map.
- If the caller hangs up first, the call is marked **Not traced**. An incident created from it has
  no location, so ask for one on the line and write it into the description.
- With no dispatcher online, the auto-incident still gets the location (nobody could trace it).

### Your own map (overlays & named locations)

![Custom overlay image and named locations on the dispatch live map](/img/dispatch/livemap-custom.svg)

`configs/cfg-livemap-sh.lua` lets you fit the live map to your server. It applies to every map:
the dispatch console, the LAPD MDT's **Map** section, the Agency MDT's **MAP** key, the LASD
terminal's **MAP** command / key, the EMS / Fire CAD's **Map** tab, the Pennsylvania CAD's **Map View**, the supervisor terminal (**Watch → Map**) and the
[web dispatcher](/features/webdispatch#your-own-map-images). The on/off choice per image is shared
by all in-game maps.

- **`LiveMap.overlays`**: draw your own image (a postal map, a custom island) over the GTA tiles.
  Give the game coordinates of the image's bottom-left (`from`) and top-right (`to`) corner. Each
  overlay gets an on/off button in the console's top bar. Set `LiveMap.hideBaseTiles = true` to
  show only your images. Add a public `webUrl` to show the image on the
  [web dispatcher](/features/webdispatch#your-own-map-images) too.
- **`LiveMap.locations`**: named places, as a circle (`x`, `y`, `radius`) or a polygon
  (`points`). They are drawn on the live map (and on the
  [web dispatcher's](/features/webdispatch#named-locations) map), and a 911/311 call placed inside one carries the
  name in front of the street, e.g. *Paleto Valley Mall, Great Ocean Hwy*. The first match wins,
  so list small places before the bigger area around them. The name is added everywhere a
  location is written: 911/311 calls, panic and backup / EMS / tow requests, traffic stops and
  Code 6, incidents raised from the LASD and EMS terminals, and the Location column of the unit
  lists. `LiveMap.nameCallLocations = false` turns that off (the map still draws them).

<Callout type="info">
  The easiest place for an overlay image is a small resource of your own: put the image in it,
  list it under `files { 'maps/postals.png' }` in that resource's `fxmanifest.lua`, and use
  `https://cfx-nui-<resource>/maps/postals.png` as the `url`. To find the corner coordinates,
  switch the console to **Admin** and click the map: it shows the game coordinates of the click.
</Callout>

## Call & unit states

Incident (call) states progress:

```
Outstanding → Assigned → On Scene → Resolved
```

Unit statuses include `CLEAR`, `ENROUTE`, `ON SCENE`, `CODE SIX`, `BUSY`, `UNAVAILABLE`,
`OUT TO STATION`. Only `CLEAR` detaches a unit from its incident — every other status keeps the
attachment.

## Incident numbering

<Callout type="warning">
  Never assume a raw `+1`. LAPD numbers roll **1000–9999** and skip currently-active numbers; LASD
  uses its own `[STATION][MMDDYY]-[TAG]` scheme; other agencies have their own format.
</Callout>

## Backup, EMS & tow

Backup / EMS / tow buttons create a real dispatch incident and broadcast it to all units. The
special-contact types that spawn incidents include 911, 311, Panic, Requesting LEO, Fire/EMS,
Coroner, Tow Truck, Crime Broadcast, Shot Spotter, and Created Incident.

## External dispatcher

Prefer an out-of-game dispatcher on a second screen? LACORE has an optional
[Web Dispatcher](/features/webdispatch) portal that mirrors the console in the browser.

## Whitelabel

Anything the MDT / CAD shows can be renamed at runtime via `configs/cfg-mdt-labels-sh.lua` — no
locale edits, no rebuild. See [Localisation — whitelabel](/configuration/localisation#renaming-cad-labels-without-translating-whitelabel).
