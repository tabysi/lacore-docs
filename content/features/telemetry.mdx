# Nothing leaves your server

Since **4.2.0** LACORE runs **fully offline**. It sends no telemetry, no server registration, no
setup report and no version check, and it fetches nothing from the LACORE website. There is no
licence key to set and no licence server to wait for on start.

![What keeps working and what is gone](/img/features/offline-build.svg)

<Callout type="info">
  Up to 4.1.0, LACORE reported server-level metadata (server registration and a setup report) to the
  LACORE home service. That service is shut down, and the code paths that talked to it are switched
  off in the resource itself — there is nothing for you to block or configure.
</Callout>

## The only outbound calls are the ones you set up

LACORE makes a web request only to an address **you** put into your `server.cfg` or `configs/`.
Leave a setting empty and that request never happens.

| What | Where you set it | Goes to |
| --- | --- | --- |
| Discord log channels | `lacore_webhook_*` convars (`Webhooks` in `configs/cfg-server-sv.lua`) | your Discord webhooks |
| Big Brother mirror | `lacore_bb_webhook*` convars (`configs/cfg-bigbrother-sv.lua`) | your Discord webhooks |
| Security alert | `lacore_alert_webhook` | your Discord webhook |
| Discord role → ACE bridge | bot token and guild in `DiscordAuth` ([Discord & Duty](/configuration/discord)) | Discord's API, to read a member's roles |
| Web dispatcher | `lacore_bridge_url` + `lacore_bridge_token` ([Web Dispatcher](/features/webdispatch)) | your own bridge |
| Screenshot uploads | `Anticheat.Evidence.uploadUrl`, `PhoneCfg.cameraUpload` | your own upload endpoint |

The screenshot uploads go through `screenshot-basic` from the player's game, not from the server,
and only when you have filled in the address.

One more runs in the player's game: the in-phone web browser opens `PhoneCfg.eyefindUrl`
(`configs/cfg-phone-sh.lua`) as its home page when a player uses it. It ships pointing at the
LACORE store page; set it to your own community's site. It is an ordinary page load and carries no
server data.

Player reports (`/report`) and bug reports (`/lacorereport`) still work. They post to your own
webhooks, `lacore_webhook_reports` and `lacore_webhook_bugreport`, if you set them.

## A leftover from the old dashboard

If your server ever used the online dashboard, a cached copy of its settings may still sit in
`data/remote-config.json`. LACORE still applies it at start, on top of your `configs/` files, and the
console says so:

```
[lacore] these values come from the old LACORE dashboard and override your configs/ files. Delete data/remote-config.json to use only your local configs.
```

Delete the file and restart the resource to run on your `configs/` alone. Nothing new is ever
written to it.

## Checking it yourself

`/lacore doctor` lists the licence key as *not needed — LACORE runs fully offline (no dashboard)*.
If you want to see it on the wire, watch your server's outbound traffic: with the settings above
left empty, the LACORE server side opens no connections of its own.
