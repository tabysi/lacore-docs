## In one paragraph

Every terminal, BOLO, charge and record sits on the **same backend**. A call raised on one terminal
is a call on all of them; a person you run comes back with the same file everywhere. Departments,
terminal skins, the penal code and permissions are all plain config files — escrow-open, commented,
no code editing.

## What it does not include

The non-LEO half of Core is deliberately left out: the **phone**, the **civilian layer**, **radio
speech-to-text**, the **web dispatcher** and the **admin/staff panel**, along with the world and
roleplay extras and their config files. If you need those, you need [Core](/).
