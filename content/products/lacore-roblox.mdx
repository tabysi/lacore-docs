# LACORE for Roblox — LEO CAD Developer Kit

The **LACORE dispatch stack, built natively for Roblox.** Duty and callsigns, 911/311 calls, a live
incident board, and a full MDT with person/plate lookups, records, BOLOs and a penal code — as a
drop-in kit for your own Roblox roleplay game.

Not a port and not a game: it is the **systems layer** you add to the game you already have, the same
way LACORE MDT is the CAD layer for a FiveM server.

<Callout type="warning">
  **In development.** The kit is feature-complete for the LEO CAD core and tested in Roblox Studio,
  but it has not shipped yet — there is no purchase link. Availability, pricing and support terms
  will be announced when it launches.
</Callout>

## What's included

- **Unit terminal (`F2`)** — go 10-8 with a department and callsign, set status
  (`CLEAR · EN ROUTE · ON SCENE · BUSY · PANIC`) and watch a live roster of everyone on duty.
- **Emergency calls (`F3`, or `/911` and `/311` in chat)** — civilians report from anywhere on the
  map; the call is located automatically and lands on every officer's board with an alert tone.
- **Incident engine** — rolling incident numbers, the LACORE call states
  (`Outstanding → Assigned → On Scene`), self-assign, Code 4, and a world marker guiding you to your
  scene.
- **The MDT (`F10`)** — the LAPD terminal: a nine-tool ribbon with printed function keys, the
  command line, status strip, section rail and incident detail.
  **11-27** looks a person up (online *and* offline players), **10-28** runs a plate. Officers add
  notes to a record and flag someone **WANTED** — persisted, stamped with their callsign.
- **Citations and arrests** — the penal code doubles as the booking form: tick the charges, then
  file a citation (fine) or book an arrest (fine and sentence). Booking serves an open want. Every
  filing persists on the person's record and comes back as their **priors** on the next 11-27.
- **Jail** — an arrest is something the arrested player feels: they are sent to your cell and serve
  the sentence, with a countdown banner telling them who booked them and for how long. Sentences
  survive a rejoin. Bring your own prison instead and one API call hands the whole thing over.
- **Discord logging** — arrests, citations, BOLOs and shift changes as embeds in the channels you
  choose.
- **BOLO board** shared live across every unit — and persisted, so a BOLO is still on the board
  after a restart until it ages out.
- **Browser dispatcher** — an optional dispatch console in your LACORE dashboard (see below).
- **Roblox-native permissions** — departments gate on group ranks, with an admin bypass list.
- **The LAPD Mobile Client look**, the same terminal design the FiveM core runs — delivered to
  licensed servers from your dashboard, so the kit you install carries a neutral fallback and every
  feature works either way.

Everything is server-authoritative: the server validates every action, and player-written text
(call descriptions, notes, BOLOs) goes through Roblox text filtering before anyone else sees it.

## Requirements

- **Roblox Studio** and a place you own. No external libraries — the kit ships with zero dependencies.
- **Game Settings → Security → Enable Studio Access to API Services** — for saved callsigns and records.
- **Game Settings → Security → Allow HTTP Requests** — only if you want the browser dispatcher.

## Install

<Steps>

### Insert the model

Right-click **ServerScriptService** → *Insert from File…* → `lacore-roblox-<version>.rbxm`.

A single `LACORE` folder appears. It sorts itself out on the first run: the shared modules move to
`ReplicatedStorage`, the client half to `StarterPlayerScripts`.

### Press Play

The unit terminal opens with **F2**. Pick a department, type a callsign like `7A-21`, hit
**GO 10-8** — you are on duty and the MDT (**F10**) unlocks.

### Make it your map

Four files, nothing else:

| Where | What you set |
| --- | --- |
| `LacoreShared/Departments` | your departments and which Roblox group ranks may join them |
| `LacoreShared/Zones` | named areas of your map (an automatic grid postal works until you do) |
| `LacoreShared/PenalCode` | the charges your officers can file |
| `LacoreShared/Config` → `Jail` | sentence length, and the part your cell is named after |
| `LacoreServer/ServerConfig` | license key + dashboard URL, Discord webhooks + proxy |

</Steps>

## Browser dispatcher

The kit can stream its CAD state to your **LACORE dashboard**, giving you a dispatcher seat in the
browser — no second Roblox client, no extra hosting.

<Steps>

### Point the kit at your dashboard

In `ServerScriptService/LACORE/LacoreServer/ServerConfig`:

```lua
RelayUrl = "https://lacore.netica.dev",
LicenseKey = "LACORE-XXXXX-XXXXX-XXXXX",   -- Dashboard → License keys
```

Then enable **Allow HTTP Requests** in Game Settings → Security.

### Open the console

Sign in to your dashboard and go to **Dispatch**. Your units and calls appear within about two
seconds, and the console can set a unit's status, assign it to an incident, or Code 4 a call — the
game picks the order up on its next push.

</Steps>

<Callout type="info">
  Your game server also appears under **Servers** in the dashboard, so a Roblox place sits next to
  your FiveM servers with the same license status.
</Callout>

## Jail

An arrest writes the record either way. What it *does* to the player is up to `LacoreShared/Config`
under `Jail`:

- Put a part named **`LacoreJailCell`** anywhere in your Workspace — that is where arrested players
  land. Optionally a **`LacoreJailRelease`** part for where they walk out.
- `MinutesPerMonth` converts the penal code's sentence into real time; `MinMinutes` / `MaxMinutes`
  keep a 120-month murder charge from taking someone's evening.
- `CellRadius` is how far an inmate may stray before they are put back.

If the cell part does not exist, the arrest still files and nobody is teleported — a missing build
never swallows an officer's paperwork. Set `Enabled = false` and an arrest is purely a record.

Already have a prison? Hand jail over completely:

```lua
LacoreApi.setJailHandler(function(userId, minutes, months, byCallsign)
    MyPrison:lockUp(userId, minutes)
end)
```

The kit then stops teleporting, timing and storing sentences — every booking calls your function, and
releasing is yours.

## Discord logging

Put a webhook URL into `LacoreServer/ServerConfig` under `DiscordWebhooks` — per category
(`arrest`, `citation`, `bolo`, `duty`) or one `default` for all of them. Anything left empty simply
does not log.

<Callout type="warning">
  **Discord refuses requests from Roblox's servers.** A webhook posted straight to `discord.com`
  returns 403 in a published game — but works in Studio, because Studio sends from your own
  connection. Testing alone will not show you this. Something has to forward.
</Callout>

**If you already set `RelayUrl` and `LicenseKey`, you are done** — your dashboard forwards for you,
and there is nothing else to sign up for. The webhook only ever travels server to server, LACORE
rebuilds the embed rather than passing your payload through, and only real Discord webhook URLs are
accepted.

Running without the uplink? Set `DiscordProxy` to a forwarding host (the public
[WebhookProxy](https://webhook.lewisakura.moe/) at `webhook.lewisakura.moe`, or your own) and LACORE
swaps the host in — paste the webhook URLs exactly as Discord gave them either way.

The startup line tells you which path is live: `Discord logging: via LACORE relay`, `via <proxy>`,
`direct` (the one that breaks on publish) or `off`.

## Game integration

Roblox has no built-in vehicle registry, so the plate lookup reads what *your* game tells it. Register
a vehicle from any server script:

```lua
local LacoreApi = require(game.ServerScriptService.LACORE.LacoreServer.Api)

LacoreApi.registerVehiclePlate("4ABC123", "John Doe", player.UserId)
```

`10-28` on that plate now returns the registered owner.

Reading back what the terminal decided works the same way — a jail script wants the sentence an
officer just handed down, an economy script wants the fine:

```lua
local record = LacoreApi.getRecord(player.UserId)

for _, filing in record.filings do
    -- filing.kind is "CITATION" or "ARREST"
    print(filing.kind, filing.fine, filing.months, filing.by)
end
```

The API surface is deliberately small and stable — see the [Developer API](/developer-api) page for
the philosophy it follows.

## What it does not do

Being straight about the edges, because a CAD that promises the world helps nobody:

- **No voice and no radio.** Roblox voice routing is not part of the kit.
- **No vehicles, map or characters** — that is your game. The kit is the CAD layer on top.
- **Calls are visible to every on-duty unit**; per-agency routing (LEO vs. Fire/EMS) is planned.
- **No live sync between server instances.** Each instance runs its own roster and call board;
  BOLOs are merged when they are saved, so nothing is lost, but a BOLO posted next door shows up
  when that instance restarts, not a second later.
- **Roblox has no escrow.** Anything you buy on the platform ships as readable source — that is true
  of every Roblox kit, ours included. The kit is licensed per customer, and the dashboard,
  dispatcher, terminal look and updates are what the licence keeps you connected to.
