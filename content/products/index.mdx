# LACORE Products

**LACORE Core** is the complete stack: law enforcement, civilian layer, phone, admin tools and
security in one resource. Everything on this page is a way to buy *less* than that, or to add
something on top.

Each product has its own section here — what it is, what it includes, how to install it, and the
questions people ask before buying.

## Which one do I need?

| | Runs as | Needs Core | Best for |
|---|---|---|---|
| **LACORE Core** | Own resource | — | A complete server, LEO **and** civilian |
| **LACORE MDT** | Own resource | No | You have a framework and want a real CAD |
| **9100-T CAD** | Own resource | No | One department, one terminal, heavy on atmosphere |
| **Pennsylvania CAD** | Inside Core | Yes | A county-style terminal beside your other CADs |
| **LACORE for Roblox** | Roblox project | No | Roblox roleplay games (in development) |

<Callout type="info">
  **One purchase = one server.** Every paid LACORE product is escrow-protected and IP-locked to a
  single server. Running a second server means a second licence.
</Callout>

## How delivery works

- **Standalone resources** (Core, MDT, 9100-T) arrive as a download you drop into `resources/` and
  `ensure` in your `server.cfg`.
- **Add-ons** (Pennsylvania CAD) ship *inside* Core and switch themselves on once your licence key
  carries the entitlement — there is no second resource to start.
- Either way, set your key with `set lacore_license_key "…"` in `server.cfg`. See
  [License keys](/customer-portal/license-keys).
