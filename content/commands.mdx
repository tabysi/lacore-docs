# Command Reference

Every `<arg>` is required, `[arg]` is optional. Many commands only work in a certain role
(Civilian / LEO / Fire-EMS / Coroner / Dispatcher / Staff).

<Callout type="info">
  Command availability depends on your server's config: modules can be switched off in
  `configs/cfg-features-sh.lua`, and agency codes come from your server team. When in doubt, ask
  your team or check the [Support & FAQ](/support).
</Callout>

**Legend** — 🔒 needs an ACE permission (or the server console) · 🧪 developer / debug tool, not
meant for players. Everything else either checks your job and duty status when you run it, or is
open to everyone.

## 🧍 Character & session

| Command | Who | What it does |
|---------|-----|--------------|
| `/char [name]` | Everyone | Open your character data sheet. **Saving sets your RP name** and joins you to the session. Supports unlimited presets. |
| `/character` | Everyone | Alias of `/char`. |
| `/profile` | Everyone | Open your player profile (playtime, characters, achievements, emote radial config, **settings**). |
| `/vreg` | Everyone | Register the vehicle you're currently driving (plate, make, model, colour, owner…). |
| `/phone` | Everyone | Open / close the LACORE phone (default key **F1**). |
| `/settings` | Everyone | Open your **profile on its Settings tab** — the settings live there, not in a window of their own. On an already-open profile it switches to that tab. **The name is configurable** — see the note below. |
| `/vehicle` | Everyone* | Toggle the vehicle spawner — search by name or model code, filter by class and manufacturer. **\*Restrictable** via `VehicleSpawner.permission` (see below); open to everyone by default. |
| `/session` | Everyone | Session window — switch between the roleplay session and a personal one, and set that session's map, time and AI population. |
| `/playerlist` | Everyone | Toggle the player list (default **I**). |
| `/lacorereport` | Everyone | Report a bug straight to the [LACORE dashboard](/user-guide/bug-reports) — not your own server database. Renameable via `Report.command`. |
| `/playtime` 🔒 | — | Show your playtime. |
| `/showid` | Everyone | Show your server ID. |

<Callout type="warning">
  **The vehicle spawner is open to everyone by default.** Any player can spawn any vehicle in the
  game. To restrict it, set a permission in `configs/cfg-server-sv.lua` and grant it in `server.cfg`:

  ```lua
  VehicleSpawner = { permission = "vehiclespawner" }
  ```
  ```cfg
  add_ace group.admin lacore.vehiclespawner allow
  ```

  The check runs server-side before the window opens, and `devmode` / Staff / Dev always pass. It
  gates *this tool* — stopping a cheat client from creating vehicles is the
  [anticheat](/anticheat)'s job, not a menu's.
</Callout>

<Callout type="info">
  **`/settings` is renameable.** HUD resources commonly own `/settings` too, and two resources can't
  share a command — so ours would silently shadow theirs. Set `HudCfg.settingsCommand` to another
  name, or to `''` to drop the command entirely. The settings stay reachable either way — via the
  "LACORE: Open settings menu" keybind, or simply through `/profile` ▸ Settings.
</Callout>

<Callout type="info">
  **Adding your own setting** is one line in `settingsTemplate` (`client/core-cl.lua`) — the window
  renders that table, so a new entry appears with no UI work:

  ```lua
  { name = "Show Time", description = "Show a clock next to the minimap",
    options = "checkbox", default = true },                      -- a toggle
  { name = "Map Style", description = "The style used by the pause menu map.",
    options = { "Eyefind Maps", "Satellite" }, default = 1 },    -- a choice
  ```

  `options = "checkbox"` stores a boolean; a list stores the **1-based index** of the chosen entry.
  Read it back with `GetUserSettings("Show Time", true)` — always pass a default, since the table is
  empty until init finishes. Add `onChange = "SomeEvent"` to have that event fire whenever the value
  changes. Labels are translated when `lang/<code>.json` carries a matching key (the window derives it
  from the name: `Show Time` → `set_show_time`, description `set_show_time_d`); without one it falls
  back to the English text in the template.
</Callout>

  chat resource.
</Callout>

## ⚠️ Known command conflicts

A few names collide, either with each other or with what other resources commonly claim. None of
these break anything, but they're worth knowing when something behaves unexpectedly:

- **`X` is bound twice** — "hand on holster" and "release / uncuff". Rebind one, or turn
  `Features.rpemotes` off.
- **`/run` runs twice** — the MDT query (client) and the RP action (server) both fire. Turn
  `Features.chat.actions` off if you don't want the RP line.
- **`/settings` is claimed by many HUD resources** — rename ours via `HudCfg.settingsCommand`, or
  set it to `''` and use the keybind.
- **`/char`, `/character` and `/hangup` are each registered by more than one LACORE file.**
  The one that loads last wins, which is the intended one in a stock install — worth remembering if
  you reorder `fxmanifest.lua`. (`/prop` used to be on this list too; the scenery spawner that lost
  the name is now `/propspawner`.)
- **Turning a module off removes its commands entirely**, which is the point: the name is then free
  for whichever resource you'd rather have own it. See
  [Feature toggles](/configuration/features).
